# 已知未完成的部分

翻譯與 UI 已經全覆蓋，以下是還留著英文或還沒驗到的地方。列出來比假裝做完有用。

## 烘進美術裡的英文（baked art）

有些字不是文字，是**畫**在圖裡的，不會經過翻譯查表。目前還留英文的：

| 位置 | 內容 | 版本 |
|---|---|---|
| 阿寇達號走廊 | `RED ALERT` 警示牌 | VGA |
| 阿寇達號走廊 | `TILL DETONATION` 倒數計時器面板 | VGA |
| 開場製作群 | `GAME DEVELOPMENT SYSTEM BY…` | EGA |
| 標題 | `SPACE QUEST` logo 本體、`CHAPTER ONE` 緞帶 | 兩版 |

標題 logo 是**刻意不動的**——原版美術保留，中文以副標形式疊在旁邊（見 README 的截圖）。

警示牌與計時器面板技術上可以做：VGA 的 view 是 8-bit cel 點陣圖，可以解碼、擦掉英文、重繪中文再編回去（`tools/vga/sci1_view.py`）。還沒做。

## 還沒實機驗過的

- **macOS 完整版**：`.app` 在 Linux 上既不能簽章也不能啟動，包是「下載 CI 產物 → 本機注入遊戲與 ROM」組出來的。**必須在 Mac 上跑一次 `修復-macOS.command` 再開一次 `.app`** 才算驗收完成。
- **完整流程通關**：目前驗到的是開場、標題、對話框、選單、道具欄、狀態列與前幾個場景。中後段（柯羅娜星地底、尤倫斯荒原、代爾它號）的對白已翻譯並通過機械驗證，但沒有逐幕實機看過。

## 翻譯層面

- 三支檢查工具（`validate_batch.py` / `scan_zh.py` / `nameaudit.py`）測不到語意層面的錯：因果講反、指涉不明、梗沒翻出來。這些只能靠實機 playtest。翻解謎句時已逐條對照 [1991 年攻略整理](walkthrough-cht-1991.md)，但沒有全部實地驗證過。
- EGA 版有 44 則是純控制碼字串（沒有可翻的文字），不列入翻譯範圍。
- EGA 的 LOGIC 95 整支是 AGI 除錯器的 opcode 名稱表（187 則），刻意排除。
