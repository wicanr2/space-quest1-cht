# 《宇宙傳奇I》繁體中文化 — 翻譯指令（給翻譯 subagent）

2. `../glossary/GLOSSARY.md`（譯名，唯一權威）
3. `../glossary/PUZZLE_FACTS.md`（機關因果，翻解謎句前必查）

## 定位一句話

**衰尾主角自嘲，旁白在旁邊看熱鬧，用台灣人日常會脫口而出的中文講法。**

《宇宙傳奇》全系列是美式惡搞科幻喜劇。主角羅傑·威爾科是銀河系最廢的清潔工，運氣爛、常常莫名其妙送命。敘事是第二人稱（「你」），旁白帶著對主角的調侃。死亡訊息尤其愛用誇張又幸災樂禍的語氣。

## 「台式」的定義（容易誤解，先看清楚）

**指台灣中文的口語自然度，不是台語。** 不要加台語詞、不要地域腔調，加了反而讓部分玩家讀不順。判準只有一條：**把譯文唸出來，像不像台灣人講話。** 像說明書、像新聞稿、像對岸配音，就是還沒到位。

| 面向 | 這樣寫 | 不要這樣寫 |
|---|---|---|
| 敘述 | 你一腳踩空，整個人往下墜 | 你踏出邊緣，失去平衡並向下墜落 |
| 死法 | 就這樣掛了／直接變成一張人肉煎餅 | 你死亡了／你失去了生命 |
| 吐槽 | 這什麼鬼／你是有事嗎／想都別想 | 這是什麼／你在做什麼／這是不可能的 |
| 語氣詞 | 喔、啦、耶、欸、嘛、啊 | 哦、唄、嘞、咯 |
| 程度 | 有夠慘、超級衰、爛到爆 | 非常慘、十分不幸、極為糟糕 |
| 句長 | 短句斷開，一句講一件事 | 用「並」「且」「而」串成長句 |
| 功能短句 | 你辦不到／算了／那沒用 | 你無法執行此動作／請忽略／該行為沒有幫助 |

**「吧」不用刻意避開**，「走吧」「好吧」「醒醒吧」在台灣中文完全自然。要避的是堆疊，不是這個字本身。

## 風格基準：對齊《宇宙傳奇IV》

四代最外放，本作目標放在那一端——更多語氣詞、更敢用驚嘆號、句子更短更跳。參考句：

- 「說真的，你以為這傢伙有空跟你聊天喔？他正忙著死透呢。」
- 「老子開除你都開累了，快滾！」
- 「你一個不小心，從岩架上踩空，直接摔進裂縫底部。這麼蠢的招數，會死也是剛好而已。」

功能短句要短、要像人話：

| 英文 | 好 | 偏翻譯腔 |
|---|---|---|
| That's not possible. | 不可能啦。 | 那不可能。 |
| Be more specific. | 講清楚一點。 | 請說得更具體一點。 |
| You already have it. | 你已經拿到了。 | 你已經擁有它了。 |
| That wouldn't be helpful. | 那樣沒用。 | 那樣做沒有幫助。 |

## [HARD] 用字紅線

- **不要簡體字。** 非 Big5 的字會讓**整則譯文被丟棄**（不是只掉那個字），實機直接顯示英文。
- **不要中國大陸用語**：視頻、質量、信息、軟件、網絡、屏幕、激光、默認、菜單（指軟體選單時；餐廳菜單是正常繁中）、鼠標、內存、牛逼、忽悠、靠譜、給力、貓膩、鋥亮、咋、瞅。
  - 誤報注意：「程序」（發射程序＝procedure）、「一會兒」、「咯咯地笑」（狀聲詞）都是正常繁中。
- **標點用全形**（，。！？：；「」『』……——），但控制序列與英文片段內的半形符號不要動。
  （建構工具會自動把緊鄰中文的半形標點轉全形，所以偶爾漏掉不致命，但請直接寫全形。）

## [HARD] 遊戲內自稱一律「宇宙傳奇I」，不要寫「新宇宙傳奇I」

「**新**宇宙傳奇I」是 1991 年台灣代理在**廣告與包裝上**用來區別 VGA 重製版與 1986 原版的行銷寫法。遊戲內文（過關訊息、狀態列、片尾）原文寫的是 `Space Quest I`，就譯「宇宙傳奇I」——EGA 與 VGA 兩版共用同一份譯名，加「新」會讓兩版譯文對不起來，也不是玩家在畫面上該看到的東西。「新」只出現在 README 與專案文件裡。

## [HARD] 機械規則（違反會讓遊戲顯示錯字或崩潰）

1. **第一欄英文原文一個字都不能改**——那是查表 key，改了就查不到、顯示英文。
2. **控制序列原樣保留**，數量與相對位置都不能變：`%s` `%d` `%c` `%x` `%u`、`\n`、`\t`、`%-Ns` 這類含寬度的也算。中文句要把它擺在通順的位置。
   - **複數標記 `%s` 要拿掉。** 像 `You have %d Buckazoid%s` 結尾那個 `%s`，是英文用來補 `s` 變複數的，中文沒有這種語法，**留著實機會顯示「太空幣s」**。正確譯法是 `你有 %d 枚太空幣`（`%s` 整個刪掉，`%d` 保留）。
     判準：刪掉之後**該則譯文不可以再剩下任何 `%s`**（引擎的子序列對應對 `%s` 有防呆，殘留會退回英文）。所以 `You search %s and find %s` 這種真的要帶入兩個字串的，兩個都得留。
     一句話：**`%s` 是真的要插一段文字就留，只是拿來補複數 s 的就刪。**
3. **行首行尾空白照抄**——有些字串刻意用空白對齊排版。
   - 例外：中文拼接片段不需要保留原文的尾端空格（`You can see ` 那個空格是英文單字分隔用的）。
4. **長度控制在原文的 ±30%**，對話框空間有限。
5. **功能性短句照直翻，別硬塞笑點**（`Ok.`→`好的。`）。幽默留給旁白與死亡訊息。
6. 輸出是 TSV：`原文<TAB>譯文`，**行數與輸入完全相同**。

## [HARD] 譯前先確認「這句在遊戲裡是什麼情況」

最容易出錯、也最傷玩家的地方，尤其是講機關、解謎、因果的句子——照字面翻可能把機制講反，玩家照著讀會卡關。

SQ2 實際踩過：

> 原文：`Your fire and subsequent shower seems to have shorted out the burnished bullies.`
> 錯譯：「似乎把那些鋥亮的惡霸給**燒**短路了」
> 問題：遊戲裡是「點火 → 觸發自動灑水 → **水**讓機器人短路」。譯成「燒短路」因果講反。
> 應為：「你點的那把火引來一場『及時雨』，那些亮晶晶的鐵皮惡霸看來全泡到短路了。」

**解謎句一律先查 `PUZZLE_FACTS.md`。** 本作已知的因果陷阱舉例：

- 濃縮水**餵給**怪物 → 在牠**體內膨脹爆炸**（不是玩家拿水去攻擊）。
- 黏稠物**先**丟給章魚怪黏住觸鬚，**之後**才能通過（順序反了就錯）。
- 玻璃碎片**反射**雷射光去破壞防護網（不是拿玻璃去砸雷射）。
- 化石是**等蜘蛛走到下方時推下去壓死牠**（不是踩上去）。
- 自爆密碼輸入與搭逃生艙脫離是**兩個獨立步驟**。

## 不要翻的東西（第二欄照抄第一欄，原樣輸出）

- 玩家要**自己打字輸入**的東西（本作 VGA 是圖示介面，但仍可能有輸入框）：口令、密碼、指令。
- **開發除錯字串**。徵兆：混雜 `rm%03d`、`%s %s` 這類格式碼、講的是內部狀態而非劇情，例如 `New response: rm%03d %s %s`。玩家看不到，翻了只是製造風險。
- 專有名詞的英文原文若出現在需要玩家比對的畫面上，保留 ASCII。
- 純數字、純符號、單一字母的字串。

## 遇到表上沒有的自創惡搞名詞

《宇宙傳奇》滿滿是自創商品名／機器型號（`Abdo-Seal abdomen filler`、`Model DX Cartridge Retrieval Unit` 之類）。做法：

1. **把梗翻出來**，不要純音譯（這是本系列的招牌）。
2. **同一批內前後一致**。
3. 在最終回覆裡**列出你新造的譯名**，好收進譯名表給其他批沿用。

已裁決的：`Abdo-Seal abdomen filler` → **腹腔快補填充劑**。
