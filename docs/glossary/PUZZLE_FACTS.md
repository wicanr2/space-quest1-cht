# 《宇宙傳奇I》機關因果速查（翻譯校對用）

> 來源：1991 年雜誌〈新宇宙傳奇I 完全攻略〉（撰者 Charles Angel，雜誌頁 49–55）之 OCR 整理。
> **用途**：翻解謎句、機關敘述、死亡訊息前先查這裡，確認遊戲裡實際發生什麼事。
> SQ2 曾把「水造成短路」譯成「燒短路」，因果講反，就是沒對照攻略造成的。

## 第一部分（阿寇達號 → 柯羅娜星 → 尤倫斯荒原）


1. **升降機旁沙崙士兵巡邏**：躲到滑鼠（滑鼠道具所在艙房）旁邊的陰暗處（畫面上方）可以避開沙崙士兵，等它走後再繼續前進；若停留在明處會被發現追殺。
2. **逃生艙控制室**：先按下控制台按鈕，把外部逃生艙門打開；再用鑰匙卡打開氣密室的艙門，才能進入氣密室。
3. **氣密室內**：先打開左上方的櫃子把太空裝穿上，才能安全出艙；再打開櫃子左方的小抽屜取得翻譯機。
4. **救生艇逃生**：先繫好安全帶，再按主控鍵盤最右邊的電源開關啓動小艇，然後用搖桿型操控桿把小艇開出去。
5. **主控鍵盤三個按鈕**：只有最左邊的自動導航鈕能安全飛抵凱羅娜行星；**中間的按鈕遊戲已警告不能按**，攻略作者用「你會知道作者對於十字架的另一種解釋」暗示按下去等同死亡／十字架＝墓碑的黑色幽默，**不要照字面翻成正面意涵**。
6. **凶暴的怪物（恐龍化石頭部）**：牠會把玩家搓成肉球（=玩家死亡動畫）。解法是**趁牠尚未行動前，把整瓶濃縮水丟給牠**；牠會像小狗一樣一口吞下去，濃縮水接觸怪物體內會**迅速膨脹並把牠炸成碎片**——因果是「餵水→怪物體內膨脹→爆炸死亡」，不是玩家主動攻擊。炸死後搜索殘骸可以拿到牠的虎牙。
7. **殺手蜘蛛（恐龍脊椎骨路段）**：牠會自動搜索生命體並摧毀，**玩家要小心不要靠近**；脊椎骨路段有一塊「不牢固的骨骼化石」，玩家應先在旁邊等待，等殺手蜘蛛從正下方經過時，**把那塊化石推下去壓死蜘蛛**——因果是「等待時機→推化石→壓死蜘蛛」，玩家不能自己先走過去踩那塊化石（會掉落／不牢固）。
8. **恐龍尾部標示牌／升降梯陷阱**：走近恐龍化石尾部的標示牌（太遠看不清楚）會**直接掉進一個陷阱般的升降梯**，因而進入地底世界——這是自動觸發的機關，不是玩家主動操作。
9. **石筍與黏稠物**：升降梯出口旁的石筍頭已被折斷，且被紫色黏稠物黏住；玩家要**把石筍折斷，並把黏稠物與石筍分開**，才能各自取得兩樣物品（黏稠物與石筍）。
10. **章魚怪（地底鐵籠）**：**不要立刻走過鐵籠**；要先把紫色黏稠物丟給章魚怪，牠的觸鬚會「傻傻地被黏住」，之後才能**從鐵籠左方安全通過**——因果是「先餵黏稠物→觸鬚被黏住→才能安全通過」，順序不能顛倒，否則會被觸鬚攻擊（攻略雖未明講後果，但強調「別立刻走過去」）。
11. **蒸汽石筍與門**：把石筍插在正在噴蒸汽的柱子上，門就會打開——這是插入道具觸發開門的機關。
12. **雷射防護網**：**拿起玻璃碎片反射雷射光**，即可摧毀雷射防護網——因果是「玻璃碎片反射光→破壞雷射」，不是直接打壞雷射本身。
13. **滴酸液的狹窄走道**：攻略提醒**通過前務必先存檔**，因為這段「酸雨」不簡單，暗示過關失敗率高、易死亡，需多次嘗試。
14. **綠色液體池**：**千萬不要碰到**，碰到會「溶化得只剩下骨頭」——即死亡陷阱，不是可互動的道具。
15. **翻譯機與外星怪頭對話**：進入怪頭所在密室前**要先打開翻譯機**，否則會因為聽不懂外星人說的話而**被直接送回地面**（等同任務失敗、被踢出該場景，不是死亡）。
16. **外星怪頭的委託與虎牙**：外星怪頭要求玩家消滅外面的怪物並帶回證據，獎賞是開啓六角形的門；玩家已經打死凶暴的怪物並持有牠的虎牙，**把虎牙拿給怪頭看**，六角形的門就會出現——因果是「出示虎牙證據→怪頭開門」，不是打鬥或密碼輸入。
17. **資料卡匣與自爆密碼**：把資料卡匣插入蒸汽室的資料查詢機，會顯示星球能源產生器的訊息與自爆密碼。設定緣由：科學家發明星球能源產生器是為了拯救逐漸冷卻的太陽，但預知會被覬覦，因此把設計圖藏在卡匣裡並設下自爆密碼——**若無法奪回本體，就要用密碼引爆銷毀**，避免落入沙崙人手中被拿去作惡。卡匣本身因含有完整設計資料，**必須抄下密碼後把卡匣帶走保管**，不能留下或銷毀卡匣。
18. **飛艇買賣（猶倫斯平地）**：鬼鬼祟祟的傢伙想出錢買玩家的飛艇，**攻略提醒不要立刻答應**，先假裝離開再回頭，但**離開前一定要拔下飛艇鑰匙**，否則飛艇會不翼而飛；對方會多問一兩次並提高價格、附贈個人飛行器、酒吧折價券、機器人商店折價券，等到這些贈品都到手後才可以賣掉飛艇——因果是「不立刻答應→誘使對方加碼→集滿贈品後才賣」，順序錯誤（提早答應）會少拿到贈品。
19. **酒吧折價券**：進酒吧先到吧台用折價券換一杯啤酒和五塊錢（後續步驟本次掃描範圍未涵蓋，文章在此處被截斷）。


## 第二部分（尤倫斯荒原 → 代爾它號 → 結局）

### 2. 解謎機關的因果描述（逐條摘出，供翻譯校對用）

1. **吃角子老虎機 + 強力磁鐵**：把「強力磁鐵」吸附在吃角子老虎機上 → 每賭必贏，直到機器爆掉為止 → 玩家因此致富（「小財主」）。若不吸磁鐵直接玩，同時開出三個骷髏圖案 → 下場淒慘（暗示死亡）。
2. **玩輸吃角子老虎的下場**：玩輸的人會被雷射光射成骨灰，並被清掃機器人把骨灰掃走；玩家可在酒吧背面的骨灰堆中撿到零錢（暗示前面死掉的玩家留下的錢）。
3. **買機器人／飛艇的順序**：機器人商店買導航機器人 NAV-201 時，要先給折價券再交錢；太空船商店買飛艇同理，先存進度再嘗試不同飛艇，最終要買「最北方那艘像飛彈的太空飛艇」，走到飛艇旁交錢才能買下。
4. **導航碼輸入**：起飛後導航機器人詢問目的星區並要求輸入導航碼，必須輸入先前在酒吧偷聽到的星區導航碼；輸錯星區「後果也不怎麼好喔」（暗示會有負面/死亡結局，但未寫明細節）。
5. **抵達沙崙人太空船後的分歧**：可選擇「接近」或「逃走」，逃走時的問句要選 NO（勇敢不逃走）→ 才能穿噴射飛行器飛向沙崙人戰艦、觸發後續進艦劇情。
6. **進入氣密室**：外部艙門開啟後，須先躲到內部艙門旁邊；等內部巡邏機器人進入艙房、趁艙門尚未關上時溜進太空船內部，否則會被射殺。
7. **躲入箱子逃過搜索**：進入太空船內部後找到一個大箱子，用「氙星軍刀」打開箱子的鎖並躲進去，若不躲進箱子「是混不去的」（過不了關）。躲入箱子後會被搬運工搬來搬去，最終被搬到洗衣室。
8. **洗衣機掉包沙崙人制服**：洗衣機裡有一套沙崙人制服，玩家進洗衣機打算換裝時，恰有沙崙士兵也進來洗衣服，玩家被困在洗衣機裡「轉阿轉」被洗；洗衣機停止後玩家已換上制服，但原本穿的太空裝已經全部破爛（換裝機關的因果：被洗＝完成換裝，太空裝報銷）。地上另有一張識別卡可撿。
9. **穿沙崙人軍裝的效果**：穿上沙崙人軍裝後可在戰艦內暢行無阻，還會有小嘍囉向玩家敬禮（偽裝生效的具體效果）。
10. **軍械室拿雷射槍**：軍械室由一個「很愛發牢騷」的機器人看管，只要把識別卡交給它，它就會帶玩家去軍械庫拿雷射槍；此時桌上另有兩個瓦斯手榴彈，需趁機器人沒注意時偷走，「動作要快」。
11. **雷射槍只能試射一次**：拿到雷射槍後可以拿機器人試打一次，但若再開第二槍「就會倒大楣了」（暗示死亡），但攻略鼓勵「死法蠻好玩的不妨試試看」。
12. **鐵甲守衛只能用瓦斯彈解決**：看守星球能源產生器的守衛全身鐵甲，雷射槍打不壞、打不贏；改丟瓦斯手榴彈才能把守衛薰倒解決掉。
13. **電梯前跌倒失去頭盔**：想搭電梯下樓破壞星球能源產生器時，會在電梯前莫名跌一跤、頭盔掉落，且立刻被清潔機器人清走（頭盔從此拿不回來），玩家此後只能靠反應力自行殺出重圍。
14. **最終破壞流程**：進入艙房後先搜守衛的身體找到「力場遙控器」，用它關掉力場；再把「自爆密碼」輸入星球能源產生器的數字面板；接著必須再次殺出重圍找到逃生室，坐上逃生小艇脫離，才算過關（自爆密碼輸入與物理逃離是兩個獨立步驟，順序不可顛倒）。
