# 宇宙傳奇 中文說明書整理（1987 年軟體世界平價版）

## 出處

本文整理自 1987 年台灣「軟體世界研究開發中心」（SOFT-WORLD RESEARCH CENTRE）發行的《宇宙傳奇》（Space Quest: The Sarien Encounter）平價版說明書，對應 **1986 年 EGA 原版**。封套標示「2 片裝，只賣 NT$110」，是當年「16 位元系列」叢書的第 18 號（封底側標「16位元系列之⑱」）。書末附錄署名「娃嫂 陳怡華」與「Chief Editor：C.C.T.」，日期為 1987 年 5 月 7 日。

內容權利歸原出版者所有，本文為重新整理改寫的要點索引，非原文掃描或逐字轉載。

**這份手冊很可能不是 Sierra 正式授權版的說明書**：封套自稱「平價版」，售價僅 NT$110，遠低於 1991 年 VGA 重製版官方代理廣告的 NT$420；書中〈啓動遊戲〉一節甚至寫著「若你認為以上步驟過於麻煩，你可以直接用母片進行遊戲」，通篇也找不到任何「翻手冊查代碼」式的防拷驗證流程。這些特徵比較像當年台灣拷貝店／同好工作室整理的翻譯版說明書，而不是原廠包裝內附件。這不代表 Sierra 原版 SQ1 EGA 沒有防拷機制，只能說「這份平價版手冊裡沒有」——防拷機制的實測留給後續獨立頁面處理。

## 劇情背景

手冊〈(一)故事〉一節用自己的敘事重述了開場設定：

俄恩星系（Earnon system）的太陽正逐年冷卻，行星氣候轉寒，農作物歉收。星系政府所在的氙星（Xenon）上，科學家研發出一項計畫，打算把一顆荒涼的星球改造成替代太陽的火球，用來解決寒冷危機。玩家扮演的主角剛拿到「環境衛生工程」學位，獲選登上阿寇達號科學船參與這項計畫的實測工作。

實驗初步成功，阿寇達號準備返航報捷，卻在通訊途中被沙利安人截聽——這支種族多年前曾因海盜行徑被俄恩政府放逐，此刻正伺機報復。他們的目的不只是搶走這項計畫的成果，還打算率領戰艦代爾它號攻打氙星、屠殺人民、迫使其他星球臣服。

遊戲開場時，主角只是個地位低下的清潔工，在雜物間打瞌睡摸魚，被爆炸震醒後才發現阿寇達號已遭沙利安人攻陷、同伴多已陣亡。接下來的任務就是在船上找出逃生辦法，並設法奪回研究成果，拯救俄恩星系。

手冊結尾附上一句雙關玩笑：「MAY THE FARCE BE WITH YOU！」（改編自電影台詞 "May the Force be with you"，FARCE 意為鬧劇）。

## 操作方式

- **啟動**：DOS 環境下鍵入 `SIERRA`，按 ENTER。
- **磁片備份**（軟碟版）：用 `COPY A:*.*B:` 把母片內容複製到已格式化的空白片，作為 PLAY DISK 使用；母片本身則收好不直接玩。
- **硬碟安裝**：把片1放進 A 槽，於 C 槽下鍵入 `A:INSTALLH`，依畫面指示把程式轉錄到硬碟（原文印刷如此，疑為 `INSTALL` 之誤植）。
- **畫面置中**：同時按 `CTRL-ALT` 及左右方向鍵調整畫面水平位置。
- **玩家命名**：片頭播完後可輸入 18 字以內的角色名稱。
- **存檔**：按 `F5`（或輸入 `SAVE GAME`）→ 指定磁碟機／目錄 → 用方向鍵選一個存檔格 → ENTER 確認 → 輸入描述文字。單一目錄最多存 12 筆。
- **讀檔**：按 `F7`（或輸入 `RESTORE GAME`）→ 指定磁碟機／目錄 → 方向鍵選擇存檔 → ENTER 兩次確認讀取，ESC 可隨時取消。
- **建議常用動詞**：`LOOK` / `LOOK AROUND`（察看，到新地點的第一件事）、`TALK`（交談，先判斷對象善惡）、`PICK UP`（撿拾，沒固定的東西都撿）、`USE`（善用手上物品試各種可能）。手冊另建議「勤畫地圖」「別灰心，有些錯誤解法會讓該題卡死（部分物品只能用一次）」「隨時存檔」。
- **功能鍵一覽**：

  | 按鍵 | 功能 |
  |---|---|
  | F1 | 顯示各功能鍵用途 |
  | F2 | 聲音開／關 |
  | F3 | 自動重複上一次輸入的指令 |
  | F5 | 存檔 |
  | F7 | 讀檔 |
  | F9 | 重新開始遊戲 |
  | F6 | 發射雷射槍（拿到 PULSERAY 後） |
  | TAB | 顯示身上物品清單 |
  | ESC | 暫停／繼續遊戲 |
  | CTRL-C | 取消剛輸入的指令字句 |
  | CTRL-R | 切換 RGB／CGA 複合訊號色彩（RGB 4 色；手冊建議用 EGA 卡可跑 16 色） |
  | CTRL-J | 設定搖桿（第一次切換到搖桿控制前需先按一次） |
  | CTRL-ALT + ←/→ | 調整畫面置中 |
  | ALT-Z | 放棄遊戲，回到 DOS |

- **移動控制**：鍵盤走數字鍵盤的九宮格對應八方向＋停止（7↖ 8↑ 9↗／4← 5停 6→／1↙ 2↓ 3↘）；PC jr 需搭配 `Fn` 鍵才能做對角線移動。同方向鍵再按一次可讓角色停下。也支援搖桿，遊戲中可隨時切換。
- **一個值得留意的線索**：指令對照表裡有一行「`ASTRAL BODY` → 星靈（密碼）」夾在開場逃生序列中（`LOOK SCREEN` → `ASTRAL BODY` → `GET KEYCARD` → …），並特別加註「密碼」二字。這份手冊本身沒有附對應的查詢表或星圖，是否對應遊戲實際的防拷驗證仍待另外查證，此處僅記錄線索。

## 當年譯名 vs 本專案譯名對照

這本說明書本身內部就有多處用字不一致（同一詞在封面、內文、封底各寫一種），並非後續版本才產生的漂移。以下整理成表，本專案一律以「本專案採用」欄為準。

| 英文 | 手冊內的寫法 | 本專案採用 | 備註 |
|---|---|---|---|
| Space Quest | 宇宙傳奇 | 宇宙傳奇 | 一致，無爭議 |
| Arcada（開場科學船） | 封面「阿冦達」／內文「阿寇達」／封底「阿寵達」 | **阿寇達號** | 同一本手冊三種寫法，本專案取「阿寇達」為準，前三代未出現，此為當年孤例 |
| Sarien(s) | 塞倫（人）／塞倫族 | 沙利安人 | 系列已對齊為「沙利安人」，不採手冊舊譯 |
| Deltaur（沙利安戰艦） | 代爾它（號） | 代爾它號 | 一致 |
| Kerona（本作主場景行星） | 封面「柯羅娜」／內文（四）節「可樂那」 | 柯羅娜星 | 同一本手冊封面與內文不同，本專案取封面「柯羅娜」與系列一致 |
| Earnon（星系） | 俄恩 | 厄爾農星系 | 手冊舊譯「俄恩」，本專案依系列基準改用「厄爾農」 |
| Xenon（行星，羅傑母星） | xenon（原文直接沿用英文，未翻譯） | 氙星 | 手冊完全沒翻這個詞 |
| Star Generator | 創新星計畫／創新太空計劃書 | 星辰產生器 | 手冊把它講成一項「計畫」而非裝置本身，框架有誤；本專案定調為裝置 |
| Orat（洞穴怪物） | 歐拉克 | 歐拉特 | 用字不同，系列已收斂為「歐拉特」 |

## 值得記的細節

- **滿分 202 分。** 書中多張截圖狀態列都顯示「Score: N of 202」，可作為之後製作分數對照表的基準。
- **把裝置講成計畫，是錯的框架。** 手冊將 Star Generator 稱為「創新星計畫」或「創新太空計劃書」，敘事角度是把它當成一份可被搶走的文件／任務代號，而不是一台實體裝置。本專案定案的「星辰產生器」明確是裝置本身，翻譯時不要沿用手冊這種「計畫」的講法。
- **書末流程圖解只走到柯羅娜星就停了。** 頁 13–24 附了一段簡化攻略（英文指令＋中譯對照＋對應截圖），涵蓋範圍是「阿寇達號逃生 → 登上救生艇 → 墜落柯羅娜星表 → 遇到地底外星生物」，最後停在一句未附翻譯的外星語「`Z Jo jb? lvoo sd fj?`」，之後的劇情（尤倫斯荒原、代爾它號滲透等）完全沒有涵蓋。
- **附錄疑似同好投稿整理，非 Sierra 官方手冊原文。** 物品介紹與流程攻略兩節分別署名「娃嫂 陳怡華 1987」與「Chief Editor：C.C.T. 7th May, 1987」，風格與前段官方劇情／操作說明的譯文明顯不同。
- **同一本手冊內部譯名就不統一**（見上方對照表），比對時要留意不能只抓一處就當定案，尤其 Arcada 出現三種寫法、Kerona 出現兩種寫法。
