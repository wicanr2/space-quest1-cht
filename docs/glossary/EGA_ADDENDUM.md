# EGA（1986 AGI 原版）翻譯附則

先讀 `INSTRUCTIONS.md`（風格、用字紅線、譯名規則全部適用），**本檔只列 EGA 版與 VGA 版不同的地方**。衝突時以本檔為準。

## 一、控制序列不一樣（最重要）

EGA 走的是 Sierra 的 AGI 引擎，控制序列跟 VGA（SCI）完全不同：

| 序列 | 意思 | 處理方式 |
|---|---|---|
| `%s1` `%s2`… | 字串變數（通常是主角名或玩家輸入的東西） | **原樣保留**，擺到中文句子通順的位置 |
| `%v81` `%v3`… | 數值變數（分數、數量） | **原樣保留** |
| `%m23` | 引用另一則訊息 | **原樣保留** |
| `%w1` `%w2` | **玩家自己打進去的詞** | **原樣保留，而且絕對不要動它周圍的語意去猜那是什麼** |
| `%g` | logic 0 的文字 | 原樣保留 |
| `\n` `\t` | 換行、定位 | 原樣保留，數量與位置都不能變 |

**[HARD] 數量必須完全相同，一個都不能增刪。** VGA 那條「複數標記 `%s` 可以拿掉」的規則**在這裡不成立**——AGI 沒有子序列對應機制，少一個就顯示錯亂。驗證器已改成嚴格模式，增刪一定 FATAL。

## 二、這一版是「打字下指令」的鍵盤介面

玩家要自己打英文指令（`look`、`open door`、`get rock`）。因此：

- **句子裡叫玩家打某個英文指令時，那個指令保留英文。** 例：`Type LOOK to see the room.` → 「打 LOOK 看看這個房間。」——不要把 LOOK 翻成中文，翻了玩家照打會失敗。
- **提示可以在中文後面補上英文原詞**，例：「拿石頭（get rock）」。
- 名詞若同時是可輸入的物件名，中文譯名照譯即可（玩家輸入靠的是 WORDS.TOK 的英文詞表，與顯示文字無關）。

## 三、這是 1986 年的原版，文字比 VGA 版精簡

1991 的 VGA 重製版把敘事大幅重寫、加長，兩版重疊只有約 5%。所以：

- **不要拿 VGA 的譯文語感硬套**，EGA 的句子短、直接，譯文也該短。
- 但**專有名詞必須與 VGA 版完全一致**（同一個譯名表），玩家會兩版對照玩。

## 四、開發除錯字串照抄不翻

AGI 的 LOGIC 抽字會撈到一些內部字串（`follow.ego`、`assignn`、`Fast` 這類單詞或帶點的識別字）。徵兆是：不成句、含點號的識別字、明顯是引擎指令名。**第二欄照抄第一欄。**

## 五、道具名

`OBJECT` 檔裡的道具名（Cartridge、Rock、Gadget、Keycard、Glass、Skimmer key…）走同一份譯名表，照 `GLOSSARY.md`。道具名要短，欄位有寬度限制。
