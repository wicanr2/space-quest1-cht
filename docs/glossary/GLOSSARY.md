# 《宇宙傳奇I》中文化譯名表（工作版）

本表是翻譯 subagent 的唯一權威。有疑問以本表為準，不要自行音譯。

**兩個來源，優先序如下**
1. **當年台灣中文資料**（1987 軟体世界平價版說明書、1991 雜誌完全攻略）——本作獨有的名詞以它為準。
2. **系列既定譯名**（SQ2／SQ3／SQ4 已對齊，見 <https://github.com/wicanr2/space-quest4-cht/tree/main/docs/glossary>）——**跨代重複出現的名詞以它為準**，即使當年資料寫法不同。理由是玩家照順序玩下來，同一個角色前後必須同名。

## 五、譯法原則

**星球／太空船／角色名音譯，設施名意譯。** 阿寇達號、代爾它號、柯羅娜是專有名詞；氣密艙、軍械庫、資料庫是功能描述。

**惡搞名要把梗翻出來，不要純音譯。** 這是《宇宙傳奇》的招牌。

**[HARD] 一旦本表定了就不准漂移。** 平行翻譯的批次很容易讓同一個名詞出現多種寫法（SQ3 出現過拉比恩／拉比翁／拉比昂三種）。收斂靠 `translation/converge.tsv`（錯誤寫法 → 正確寫法，建構時全域替換），**不要直接改譯文檔**——那些檔會從 skeleton 重新產生，改了下次就被蓋掉。

## 六、當年資料的價值與界線

當年的說明書與攻略是**譯名依據**與**解謎機關的事實來源**，但不是翻譯範本：

- 譯名：本作獨有的名詞（阿寇達、代爾它）採當年寫法，跨代名詞採系列寫法。
- 機關：翻解謎句前先查攻略確認「做了 X 實際發生什麼」，避免把因果講反（SQ2 曾把「水造成短路」譯成「燒短路」）。
- **不要照抄當年的譯文語感。** 1987 年的中文說明書是說明書腔，本專案要的是台式口語（見 `INSTRUCTIONS.md`）。
