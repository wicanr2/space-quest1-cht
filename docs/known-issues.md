# 已知未完成的部分

翻譯與 UI 已經全覆蓋，以下是還留著英文或還沒驗到的地方。列出來比假裝做完有用。

## 烘進美術裡的英文（baked art）

有些字不是文字，是**畫**在圖裡的，不會經過翻譯查表。

**已經改成中文的**（VGA）：

| 位置 | 原文 | 中文 |
|---|---|---|
| 阿寇達號走廊牆上的閃爍警示牌 | `RED ALERT` | 警報 |
| 尤倫斯荒原的酒吧霓虹招牌 | `ROCKET` | 火箭酒吧 |

做法不是「改遊戲資源」——是把重畫好的中文點陣放進 `sq1_cels.dat`，引擎在解 view cel 的時候換上去（`engines/sci/graphics/view.cpp` 的 `chtReplaceCel`）。這樣交付的檔案裡只有我們自己畫的像素，不含任何原版美術。

**還是英文的**：

| 位置 | 內容 | 版本 | 為什麼沒做 |
|---|---|---|---|
| 阿寇達號右下角倒數計時面板 | `TILL DETONATION` | VGA | 字的高度不夠，見下 |
| 遊戲內建控制面板 | `SAVE` `RESTORE` `RESTART` `QUIT` `PLAY` `VOLUME` `DETAIL` | VGA | 同上 |
| 艙門標示 | `OPEN` / `CLOSE` | VGA | 同上 |
| 尤倫斯荒原飛船展示場 | `SUX-9000`、`NAV-201`、`MAX-42` 等型號 | VGA | 是型號不是詞，維持原文 |
| 開場製作群 | `GAME DEVELOPMENT SYSTEM BY…` | EGA | 屬於原版的製作名單 |
| 標題 | `SPACE QUEST` logo 本體、`CHAPTER ONE` 緞帶 | 兩版 | 刻意保留原美術，中文以副標形式疊在旁邊 |

「字的高度不夠」是量出來的，不是感覺：倚天點陣字最小是 **16×15**，而這些招牌留給文字的橫帶只有 5～11 個像素高。

以倒數面板為例，整塊面板 61×26，上半 16 列是倒數數字（實機截到的是 `14:55`），底下寫 `TILL DETONATION` 的那條只有 5 列。硬把中文塞進去就會蓋掉數字——玩家看不到還剩幾分鐘，比留著英文更糟。要解只能連數字的排版一起改，而那在遊戲腳本裡，不在美術裡。

控制面板的按鈕是 50×15，扣掉立體邊框只剩 9 列可用；`OPEN`／`CLOSE` 標示 34×15，扣掉外框剩 12 列。都一樣的問題。

## 還沒實機驗過的

- **macOS（patch 與完整版都是）**：`.app` 在 Linux 上既不能簽章也不能啟動。patch 版是 GitHub Actions 在 macos-14 runner 上建的（SDL2 自源碼編、兩個弧 lipo 成 universal），完整版是「下載 CI 產物 → 本機注入遊戲與 ROM」組出來的。兩者都**必須在 Mac 上跑一次 `修復-macOS.command` 再開一次 `.app`** 才算驗收完成。
- **完整流程通關**：目前驗到的是開場、標題、對話框、選單、道具欄、狀態列與前幾個場景。中後段（柯羅娜星地底、尤倫斯荒原、代爾它號）的對白已翻譯並通過機械驗證，但沒有逐幕實機看過。

## 翻譯層面

- 三支檢查工具（`validate_batch.py` / `scan_zh.py` / `nameaudit.py`）測不到語意層面的錯：因果講反、指涉不明、梗沒翻出來。這些只能靠實機 playtest。翻解謎句時已逐條對照 [1991 年攻略整理](walkthrough-cht-1991.md)，但沒有全部實地驗證過。
- EGA 版有 44 則是純控制碼字串（沒有可翻的文字），不列入翻譯範圍。
- EGA 的 LOGIC 95 整支是 AGI 除錯器的 opcode 名稱表（187 則），刻意排除。
